##  Introducing ChatGPT Work
ChatGPT Work is a way to delegate real work to ChatGPT.
Use Chat when you want an answer, explanation, brainstorm, or short draft.
Use ChatGPT Work when you want ChatGPT to complete a task with a clear outcome, such as a
brief, deck, analysis, recurring update, workflow, or file you can review and
use. Learn more about  using Chat and ChatGPT Work together .
ChatGPT Work can use your files, plugins, and approved tools to retrieve information,
create finished files, run workflows, and complete work that is ready for you to
review. You can follow progress, answer questions, change direction, and
approve important actions.
On the  desktop app , ChatGPT Work can also use local files, apps, and the
browser when those tools are available.
If you have used Codex for non-coding work, you can stay in Codex or use
ChatGPT Work instead. ChatGPT Work gives you the same core capabilities with
an experience designed for everyday work.
For general usage and availability, see  ChatGPT Work and Codex  in the Help Center.

##  Continue Work across devices
If your workspace gives you Work Cloud and local computer access, sign in with
ChatGPT using the same account and workspace on each device. In the desktop app,
select  Cloud  in the composer and start a new Work task. You can continue
that conversation on desktop, mobile, or web.
Enterprise workspaces keep their existing Local/Cloud selector and default.
For example, start a task with an approved folder on your laptop, then review the
results from your phone. The cloud coordinates the task. Keep the laptop online
and connected for steps that need its files or tools.
-  Older tasks:  Tasks created before your workspace enabled local computer
access keep their original mode, including tasks in projects.
-  Computer offline:  If the computer is unavailable at the start of a new turn,
an eligible task can continue in a cloud container. The container cannot use
the computer’s files or tools or enforce its local execution requirements.
A running turn cannot switch from local to cloud execution.
-  Access turned off:  Turning off local computer access interrupts running
turns. If you still have Work access, send a new message in the existing cloud
conversation to continue without local files.
Without local computer access for Work Cloud, choose  Local  for tasks that need
your computer. Choose  Cloud  for tasks that can run without it, such as a
scheduled website check.
Workspace owners can follow the  setup and policy checks .

##  Best practices for using ChatGPT Work
Use ChatGPT Work when you want ChatGPT to complete a task, create a file, or manage work

##  Use ChatGPT Work efficiently
Choose  GPT-6 Astra  for demanding work that needs
careful reasoning, visual judgment, or a polished final file. Consider
GPT-6.1 Sol  for complex work at a lower cost than
Astra, or Luna for simpler tasks. Select from the models available in your
model selector and check  plan usage  before starting a large
task.
ChatGPT Work is best for substantial tasks that involve multiple steps, sources, or
tools, or require a completed deliverable. Longer or more complex tasks may use
more credits because ChatGPT is doing more on your behalf. Focus on the value of
the completed result, rather than the number of prompts.
Keep the task focused by setting useful boundaries. For example: “use only
these sources,” “compare the top five options,” or “stop before sending
anything.”
Use Chat instead for quick questions, short rewrites, and decisions where you
only need advice.
